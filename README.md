# Click Automation 

A simple Python auto clicker that automates mouse clicks.

## Requirements
- Python 3 installed
- `pyautogui` library

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/JeffDeveloper/Click-Automation.git
   ```

2. Open the project folder:
   ```bash
   cd Click-Automation
   ```

3. Install the required library:
   ```bash
   pip install pyautogui
   ```

## How to Run

Run the Python script in your terminal:

```bash
python clickautomation.py
```

The auto clicker will simulate mouse clicks automatically.

## Features
- Automatic mouse clicking
- Simple Python script
- Easy to run 
- Light weight

## Note
Use the auto clicker responsibly. Check the Python script for its start and stop controls before running it.
